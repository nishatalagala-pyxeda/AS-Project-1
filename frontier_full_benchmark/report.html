Accessory-power and waste-heat forecasting

Broad benchmark:15 learned model configurations and three baselines, five forecast horizons, histories from one to24 hours, three chronological development backtests, and reused October–December confirmation. Accessory power was completed first, followed by waste heat.

October–December was examined during earlier exploration. These are exploratory confirmation results, not performance on a new independent lockbox. Each horizon's model was selected using mean relative MAE in June–July, August and September, before this run scored confirmation.

Reading the results

90% coverage is the fraction of actual readings inside the forecast intervals. Static bands use validation errors; rolling bands use only already-resolved errors. Coverage substantially below90% indicates that those uncertainty bands did not transfer reliably. Point-error improvements and uncertainty calibration are separate findings.

All models use the same complete-history forecast origins. This removes data around source gaps, including many May/June records. Fixed settings give broad coverage of model families rather than exhaustive tuning. Independent verification recalculates saved metrics and interval coverage, checks common timestamps and source hashes, and confirms selection used development scores.

Only already-observed telemetry is used. Original workbook unchanged. Waste heat remains a calculated estimate with the source’s fixed thermal constants and zero-clipping assumptions. No operating changes or causal efficiency claims are implied.
